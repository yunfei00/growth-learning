11. 减法：拿走一些
12. 数量 6～10
13. 数的分解与组合 6～10

16. 基本图形
17. 空间位置
18. 长短、高矮、轻重等简单比较
19. 综合生活数学

目录来源为 `project_curated`，稳定 ID 使用 namespace UUID5，重复导入保持 canonical key、UUID、顺序、
模板和关系不变。课程不硬锁年龄，不包含进退位、竖式、乘除、分数、小数、排名、IQ 或无限 AI 出题。
