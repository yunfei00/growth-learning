# Math Learning Model V1

Math Foundation 使用 Phase 16 的 `subject=math` 和 `type=math_skill`。一个 KnowledgePoint 表示
可迁移的能力，例如数清 5 以内数量、比较多和少、理解“合起来”，不表示一道具体算式。

学习顺序遵循：实物操作 → 图形表示 → 数字符号。前置关系用于路径建议，不硬锁内容，也不会因为
后续能力通过而自动把前置 Skill 写成 Stable。儿童页一次只显示一道主要任务，答案按钮至少 64px，
支持中文听题、轻量反馈和 reduced motion。

目录覆盖分类、数量、数字符号、比较、数序、分解组合、加减含义、规律、图形、空间和简单测量。
年龄字段只是建议；学习顺序由课程、已有 evidence 和 mastery 共同决定。该路径是 Growth Learning
项目自有设计，不宣称国家标准或官方教材。
