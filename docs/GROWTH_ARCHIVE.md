# 成长档案、报告与成长书

Phase 8 把学习、阅读、科学实验和家长记录汇总为孩子私有的长期成长档案。档案只保存真实来源或明确标注的派生摘要，不制造分数，也不把一次活动解释成能力结论。

## GrowthEvent V1

`GrowthEvent` 是统一时间线条目，但不是新的原始事实来源。每条自动事件保存：

- `source_type`、`source_entity_type`、`source_entity_id`，用于追溯原始记录；
- 生成时的最小 `evidence_snapshot` 和 `policy_version=growth-event-v1`；
- 稳定的 `idempotency_key`，数据库按孩子唯一约束阻止重复投影；
- `actor_user_id`，手工记录可证明是谁添加的；
- 可归档/纠正元数据，但不覆盖原始学习、阅读或实验记录。

自动投影规则是确定性和可重建的：学习接触、稳定掌握里程碑、已完成周/月检测、每次完成阅读、累计 10 次阅读、每次完成科学实验、累计 5/10 次实验，以及实验中的孩子原话和提问。里程碑阈值属于 `growth-event-v1`，以后修改必须发布新版本而不是静默改变旧解释。

安全重建命令：

```bash
docker compose exec backend python -m app.cli.growth rebuild-growth-events
docker compose exec backend python -m app.cli.growth rebuild-growth-events --child-id CHILD_UUID
```

重建只补齐缺失的自动事件；不会删除或覆盖手工记录，也不会修改任何原始证据。重复执行结果相同。

## 手工成长记录和私有媒体

家庭 `admin` 与 `companion` 可追加手工记录。正文按输入原样保存，展示时不进行 AI 改写。附件对象保存在私有 MinIO，键名仅包含 UUID；浏览器必须通过家庭鉴权 API 读取，平台系统管理员不会自动获得访问权。

## 真实报告

月报、年报和自定义区间报告先固定日期范围和数据快照，再用确定性服务计算：

- 学习接触、当前掌握层级、复习积压和字库范围识字估算；
- 阅读完成方式、主题、理解题结果；
- 科学实验完成数、真实标题、孩子原话和非评分行为标签；
- 家长手工记录。

样本不足会明确返回“数据不足”。识字估算始终保留“仅代表当前系统字库范围”的说明。AI 叙述是可选且单独存储的派生内容；Provider 未配置或调用失败不会阻止确定性报告生成，也不会改写指标。

`GrowthReportVersion` 不可变。相同报告再次生成只会新增版本，旧版本仍可回看。

## 我的成长书

成长书由家庭管理员从该孩子可访问的事件和媒体中选择内容，生成新的不可变 `GrowthBookVersion`。版本保存所选条目快照、真实阅读/科学事实和家长寄语。重新编辑产生新版本，已打印或回看的旧版本不改变。

打印页面使用专用 print CSS，可由浏览器“打印/另存为 PDF”。它不引入服务端 PDF 生成依赖，也不展示推断性能力分数。

## 权限边界

- 家庭 `admin`：查看时间线、追加记录、生成报告、编辑成长书、请求家庭导出。
- `companion`：查看时间线、追加陪伴记录；不能生成报告、成长书或家庭导出。
- 跨家庭请求统一不返回私人资源。
- `system_role=admin` 只管理平台知识库，不能读取任意家庭档案、报告、成长书、附件或导出。
