# English Learning Model V1

英语是独立 `subject=english`，不借用语文拼音或数学状态。儿童路径按“听 → 看 → 理解 → 使用 →
字母/拼读连接”组织；未完成 26 个字母不会锁住词汇听力。

学习页一次只呈现一个核心内容或一道题。词汇和短句先提供声音与可理解视觉，学习阶段再连接英文
文字；Listening 题的选项不显示目标拼写。Letter name、大小写配对和 phonics sound 是不同活动。

总览分词汇、字母、phonics 和短句显示真实进度，不显示英语总分、同龄排名、速度评价或“背了几个
词”的奖励。Today 每天最多 3 个新内容和 6 个到期复习，约 5～10 分钟；完成后仍可重新进入练习，
但同一 session 不会重复创建 canonical evidence。

孩子可以重复播放声音；重播不是提示。明确展示中文解释才设置 `hint_used=true`。家长可记录自然
口语表现，不要求孩子必须开口，也不做自动发音或口音评分。完整 Catalog 和系统边界见
[English Foundation V1](ENGLISH_FOUNDATION_V1.md)。
