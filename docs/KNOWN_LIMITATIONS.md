# V1 已知限制

- AI 故事生成是可选能力；生产必须配置 OpenAI-compatible runtime Provider、Base URL、API Key 和 Model。未配置时已有故事与本地证据可用，生成入口明确降级。
- 1,200 字汉字目录和课程阶段是 Growth Learning 项目定义，不宣称教育部、教材或商业产品官方标准；数据 provenance 单独保存。
- V1 没有孩子独立账号。Child Mode 由已登录家庭成员在当前设备进入，不替代成人会话授权。
- 当前数学、英语和拼音是项目自有的启蒙 V1 路径，不宣称覆盖完整教材体系；写字课程尚未实现。
- 英语 V1 的正式真人录音和静态插图只覆盖少量 smoke 内容；其余普通内容使用固定 en-US TTS 或
  人工视觉回退。Phonics 缺少正式音素录音时只播放安全示例词，因此不能替代真人教师的发音指导。
- 英语 V1 不做自动发音评分、口音评分、速度排名或开放式语音识别。
- Growth Book PDF 使用浏览器 Print / Save PDF 路径，没有服务器端排版引擎。
- Teacher collaboration 是家长逐孩子授权的轻量协作，不是学校级 LMS；没有教务、考勤、收费、群聊或排名。
- 没有排行榜、百分位、全局能力分或儿童间比较。
- V1 运维依赖单机 Docker Compose 与人工审计的备份/恢复流程，不定义企业 SLA 或声称经过外部渗透测试。
